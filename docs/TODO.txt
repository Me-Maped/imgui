issue 编号（#）对应 https://github.com/ocornut/imgui/issues/XXXX 中列出的 GitHub issue

本列表维护得并不好。如今大部分工作都在 GitHub 上进行。

以下列表主要包含在用户提出请求/讨论之前记录下来的想法（一旦被用户请求/讨论，它们通常就已经存在于 GitHub issue 跟踪器中了）。
这主要是一堆个人笔记，可能并不完整。如有任何疑问，欢迎提出。
